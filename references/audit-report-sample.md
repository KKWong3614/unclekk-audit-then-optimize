## 0. 你交给独立审计员的「审计上下文包」(Audit Context Package)

> 叶节点子代理没有技能目录感知，**永远给绝对路径**。下面是一份可直接粘贴的包。

```
【技能目录绝对路径】
<SKILL_DIR>   （真实格式示例：C:/Users/user/.workbuddy/skills/@user_48f048de/<你的技能名> —— 必须指向真实存在的技能）

【文件清单】（运行：find <SKILL_DIR> -type f | sort）
<SKILL_DIR>/SKILL.md
<SKILL_DIR>/references/...（按实际列出）
<SKILL_DIR>/examples/...（按实际列出）
...（其余文件）...

【SKILL.md 前 100 行】（略，粘贴原文前 100 行）

【先前发现（让审计员跳过看，而非重新发现）】
- 首轮已发现 P0-3：触顶判定算法与进化实例矛盾
- 本次重点核对该项是否真被修复

【首要指令】
"首要任务是问『这个设计是对的吗？』，而不是『这段代码写得漂亮吗？』"
```

## 1. 独立审计报告 A（优化前基线）(Independent Audit Report A)

> 由 leaf 子代理（fresh 上下文，toolsets=['file','terminal']）产出。

```
══════════════════════════════════════════════════════
审计对象：unclekk-darwin-evolver
审计轮次：第 1 轮（独立，优化前）
量规：skill-audit 8 阶段 /100
评分：A = 68 / 100
══════════════════════════════════════════════════════

发现清单（P0/P1/P2）：
P0-1  触顶规则「连续2轮Δ<2」未在代码中强制，仅文档说明
P0-2  evolve_trigger 在边界条件下会无限循环（无最大轮次硬上限）
P0-3  自带进化示例违反自身触顶规则（反例），属算法缺陷非措辞缺陷
P1-1  failure-modes 计数与正文不一致（正文 10 类 / 文件 11 类）
P1-2  results.tsv 模板 dimension 字段允许空值 '-'
P2-1  README 缺少 Windows 路径候选
P2-2  无单测覆盖触顶判定
...（共 3×P0 + 5×P1 + 8×P2）

结论：算法层有 3 个 P0，优化器自评前必须先修 P0。
```

## 3. 独立复审报告 C（Independent Re-Audit C）

> 由**另一个** fresh leaf 子代理（非优化器上下文）产出。

```
══════════════════════════════════════════════════════
审计对象：unclekk-darwin-evolver（优化后）
审计轮次：第 2 轮（独立复审）
量规：skill-audit 8 阶段 /100（与 A、B 同量规）
评分：C = 82 / 100
API 调用：8    耗时：304s
══════════════════════════════════════════════════════

复审发现（优化器漏改的残留缺陷）：
P1-新1  触顶判定算法仍与进化实例矛盾（P0-3 深层残余未真修）
P2-新1  failure-modes.md 计数残留（10 类 vs 11 类）未同步
P2-新3  results.tsv dimension 字段 = '-' 仍存在
P2-新4  results-tsv-template.md 的 SHA 示例含非法字符

结论：B(86) − C(82) = +4 > +3 → 自评分虚高，以 C 为准。
```

## 4. 差值决策与行动（Delta Decision & Action）

```
比较：A=68  B=86  C=82
─────────────────────────────────────────
① B − C = +4  →  超过 +3 阈值
   判定：自评分虚高。丢弃 B 的发现，以 C 的 4 条发现为权威修复清单。
② A → C：68 → 82，+14
   判定：优化确实有效（真实进步），但没优化器吹的 +18 那么多。
③ 行动：主代理按 C 的 P1-新1 / P2-新1 / P2-新3 / P2-新4 逐条修复，
   修复后无需再跑完整闭环（除非又产生自评分）。
─────────────────────────────────────────
权威最终分 = C = 82 / 100   （经主代理交叉核对后成立）
```
